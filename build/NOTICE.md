# Candidate rights and notices

The MOSAIC author has not yet selected the public code license. No license grant is inferred from this candidate's creation. The intentionally fictional demonstration text and generated source PDF are identified separately from code, dependencies, fonts and model terms.

`config/public_wheel_inventory_v1.json` records package metadata, exact downloaded wheel hashes, declared dependencies and each wheel's license/notice paths. Metadata is evidence for review, not a completed rights determination. The runtime install retains wheel-provided notices in the isolated environment.

`THIRD_PARTY_INVENTORY.json` provides the package-level metadata and notice paths
for that exact wheel inventory. `ADAPTED_SOURCE_PROVENANCE.json` maps exported
adaptations to source hashes and reuse records without including private roots
or source data. Missing declarations and redistribution decisions remain
explicitly unresolved; these appendices do not supply a license grant.

PyMuPDF is identified by its distribution as dual-licensed under GNU Affero GPL 3.0 or an Artifex commercial license. This requires an explicit compatibility review before public distribution; a generic permissive label for MOSAIC does not resolve third-party obligations.

The approved frontend includes Encode Sans, Encode Sans Semi Condensed and IBM Plex Mono fonts. Their supplied license texts are retained with the frontend assets. Source adaptations under `mosaic/adapted/` retain provenance comments; their reuse and redistribution basis require author review before release.

No model weights are included. No private PDFs, source crops, scientific extractions, provider replies, research reference keys or private ledgers belong in the export.
