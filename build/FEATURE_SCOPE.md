# What this public candidate reproduces

The public artifact builds MOSAIC's infrastructure using the user's own sources.
The author's private installation is a separate demonstration. A recording of
that installation must not imply that its corpus, saved reviews or recovered
historical data ship in this repository.

| Capability | Public candidate | Private demonstration and remaining work |
| --- | --- | --- |
| End-to-end software route | Locked Windows install; fictional native capture, extraction-driver replay, indexing and serving. CPU Linux execution is recorded separately in the wrapper's validation summary. | A successful real-model extraction remains unobserved; fixture success cannot substitute for it. |
| Own PDF corpus | Explicit registration, native capture, local-model preparation and execution commands, source-bound materialization and serving. | The operator supplies permitted PDFs, local model files, a running model endpoint and review inputs. The package does not automatically rent or configure a remote GPU. |
| Papers and APA | Literal source selections generate review receipts; only complete admitted identities and citations display. | The private corpus contains accumulated reviews. Automatic high-quality metadata recovery for arbitrary PDFs is not established. |
| Measures and item text | Reviewed literal instrument labels and item selections produce item-bearing Measure versions. The command-line helper computes hashes and preserves witnesses. | The private wording-first search, lazy loading and recovered EVOKE item collection have additional implementation/data layers. Their complete behavior is not claimed for this export. Selected items do not imply a complete instrument. |
| Source reader | Abstract/body/appendix projection, separate raw capture, literal page and PDF links. | Private cross-page context repairs and their reviewed overlays are not included as data. General automatic quotation completeness remains an evaluation task. |
| Citations | Literal reference witnesses, explicit reviewed edges and separately labeled discovery paths. | The private corpus's accumulated reference graph does not ship. DOI identity resolution and bulk metadata repair are separate capabilities. |
| Literature assistant | Offline evidence preview; opt-in server-side model drafting; source-linked author-year citations; exact supporting spans; visibly labeled research suggestions. | The new public adapter is tested with fake responses. This does not transfer the private adapter's live-test evidence or establish semantic accuracy. |
| Jev | Explicit optional post-extraction sidecars, budget and scope checks, retained replay. | It cannot govern extraction, visibility or scientific qualification. Private provider outputs and ledgers are excluded. |
| Scientific validation | Mechanical checks, deliberate failure cases and transparent uncertainty. | No public permitted real-source evaluation set or independent semantic accuracy estimate is included. Historical missing-fixture gates remain pending. |

## Conditions for a public release

This remains a review candidate until the author selects a code license and
resolves dependency and adapted-source obligations described in `NOTICE.md`.
An AGPL or commercial dependency cannot be cleared by merely adding a permissive
license to this project. The package must also retain the distinction between
source text, model interpretation, source review and scientific validation.

The submission should identify the tested archive through `VALIDATION.json`,
show the reproducible fictional workflow, and label any private screen recording
as a private installation with extra corpus and review data. It should state
which features in that recording are additional to this candidate.
